# Процедурный банк · кандидат v1

12.10.2026. Источник/редактируемый рецепт: `WorldGenesis/Assets/_Project/Scripts/Runtime/Audio/ProceduralAudio.cs`, классы `ProceduralAudio` и `ProceduralSound`. Это собственный оригинальный синтез для World Genesis; сторонние записи, извлечённые звуки WorldBox и платные сервисы не использованы. Референс не прослушивался: характер звука — наша предложенная интерпретация тихой песочницы.

PCM создаётся один раз при `Awake`: mono, 22050 Hz, два воспроизводимых варианта каждого события. Отдельных WAV-мастеров пока нет; именно эти массивы используются `AudioClip.Create`/`SetData`. Изменение рецепта требует нового прослушивания. [Unity AudioClip.Create](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AudioClip.Create.html), [SetData](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AudioClip.SetData.html).

Триггер — новый `WorldEvent.Id`, исход симуляции звук не вычисляет. При смене ссылки мира активные голоса останавливаются, история событий пропускается. Смерти намеренно не озвучены в этом банке, чтобы толпа не создавала непрерывный шум. Для поселений действует 1.3 s cooldown на тип события, для остальных 0.18 s. При занятых четырёх голосах новый эффект пропускается; воспроизводимые хвосты не обрываются. Атмосфера — пятый отдельный источник, 2D-панорама эффектов учитывает положение камеры.

Общая громкость по умолчанию 0.12, амплитуда одного PCM-эффекта не выше 0.55; атмосфера значительно тише. Это технический запас, не измерение LUFS или воспринимаемой громкости. На паузе фон плавно становится тише; эффекты ручных воздействий могут звучать. `Muted`/`ToggleMuted()` управляют всеми источниками, настройка сохраняется в PlayerPrefs. Клавишу **M** подключает интегратор; этот компонент сам не читает клавиатуру. События во время mute не воспроизводятся задним числом.

Интеграция: добавить `ProceduralAudio` на объект `GameBootstrap` после подготовки основного компонента. Генерация использует собственный локальный xorshift, не RNG мира. `Update` не создаёт PCM/AudioClip и не выделяет управляемые коллекции; голоса и клипы освобождаются при уничтожении.

Технический прогон 12.10.2026 03:00 +03:00: чистый производственный синтез загружен в память .NET, без Unity playback. Все 22 варианта имеют конечные ненулевые отсчёты, пик ≤0.55 и нулевые начало/конец. Максимальный модуль DC около 0.00116. Атмосфера: peak 0.26268, переход последнего отсчёта к первому 0.00403 до ослабления источником; это диагностическая величина, а не результат прослушивания loop.
