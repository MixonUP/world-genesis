# Исходные ресурсы

Здесь хранить собственные, процедурные, AI-созданные и разрешённые сторонние исходники тайлов, спрайтов, UI, VFX, звуков и рецептов. Пользователь разрешил выбор и сочетание этих способов 12.10.2026. Импортируемый результат — `WorldGenesis/Assets/_Project/Art` либо `Audio`. В `manifest.csv` зарегистрировать источник, права, пути, хеш и статус до включения в сборку. Исходную версию готового ресурса сохранять отдельно от доработанной; для генерации сохранять рецепт, параметры, seed и версию инструмента.

Пока ресурсов нет. Пустой реестр не является лицензированием будущих ресурсов. Референсы WorldBox не включать в runtime-ассеты. Большие материалы не копировать в Obsidian.
