Критические отказы: потеря сохранения, неверные ссылки/ID, бесконечное размножение ресурсов, зависание на маршруте, сквозной ввод UI, повреждение проекта генератором. Проверять по реальной области изменения, не писать зеркальные тесты каждой строки.
