## Задача и работающий результат

Unity 6000.0.45f1, Windows, собственный симулятор по референсу WorldBox. Пользователь разрешил автономную работу, ассеты, субагентов, документацию, снимки и GitHub. Репозиторий https://github.com/MixonUP/world-genesis теперь **public** по прямому запросу пользователя; ветка codex/world-genesis. Полнота WorldBox остаётся целью и не достигнута.

Первый цикл генерация → заселение → добыча/строительство → силы → save/load сохранён. В 0.2.0 добавлены Tiny Swords old CC0-анимации людей, еда/отдых/общение/гражданские профессии, формы правления и живые правители. Новый мир не создаёт стражников/рыцарей. При местной угрозе взрослый защищается временным ополчением и возвращается к работе; дети/тяжелораненые бегут. Исследования и физическая выдача снаряжения отсутствуют в Runtime, поэтому постоянный найм пока недоступен. Старые экспериментальные Guard демобилизуются; schema1 сохранена, BehaviorVersion2/PoliticsVersion1 мигрируют без расхода RNG.

Сборка: `Builds/Windows-0.2.0/WorldGenesis.exe`; прежняя `Builds/Windows` сохранена. Unity-проект: `WorldGenesis/`, сцена `Assets/_Project/Scenes/Main.unity`. Управление: [PLAY_GUIDE](Development/PLAY_GUIDE.md). Итог: [CITIZENS_REPORT](Development/CITIZENS_REPORT.md).
