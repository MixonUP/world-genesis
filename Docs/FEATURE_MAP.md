# Карта соответствия WorldBox

Это начальная карта направлений, **не исчерпывающий список всех функций оригинала**. Источник R01 — [Steam](https://store.steampowered.com/app/1206560/WorldBox__God_Simulator/), R02 — [официальный сайт](https://www.superworldbox.com/). Подробные алгоритмы не исследованы. Все строки сейчас `planned`, реализация отсутствует.

Метки будущего покрытия: `planned`, `implemented-unverified`, `verified`, `partial`, `unknown`, `accepted`. Критерии испытаний используют отдельные статусы в ACCEPTANCE. Назначение позднего этапа не удаляет функцию из полной цели.

Не считать работу завершённой по количеству строк или числу кнопок. Для каждой функции перед реализацией добавить наблюдаемое поведение, крайние случаи, отличия от оригинала и ссылку на доказательство. Неизвестные функции из подробного исследования добавлять новыми ID.
