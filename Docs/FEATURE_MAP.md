Источник R01 — [Steam](https://store.steampowered.com/app/1206560/WorldBox__God_Simulator/), R02 — [официальный сайт](https://www.superworldbox.com/). Подробные алгоритмы оригинала не установлены. Метки покрытия: `planned`, `implemented-unverified`, `verified`, `partial`, `unknown`, `accepted`. Критерии испытаний используют отдельные статусы в ACCEPTANCE. Назначение позднего этапа не удаляет функцию из полной цели. Таблица этапов выше остаётся маршрутом полного запроса; фактический статус определяется таблицей ниже.

Не считать работу завершённой по количеству строк или числу кнопок. Для каждой функции перед реализацией добавить наблюдаемое поведение, крайние случаи, отличия от оригинала и ссылку на доказательство. Неизвестные функции из подробного исследования добавлять новыми ID.
