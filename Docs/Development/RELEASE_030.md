# World Genesis 0.3.0-alpha — ресурсы, жители и указы

Windows x64, Unity6000.0.45f1. Распакуйте ZIP целиком и запустите WorldGenesis.exe.

- 11 видов добываемых узлов, восстановление, ноша до1единицы и настоящая доставка.
- Костёр/лесопилка/каменная мастерская/печь: доски, дрова, блоки, плитка и кирпичи.
- Общие и личные партии; бесплатная выдача либо бартер по решению правителя, натуральный налог0–30%.
- Мужчины, женщины, дети; учёба, детский труд12–15 по закону, указы о распределении и добыче.
- Каталог32разумных и ошибочных решений правителя; будущие механики отделены от работающих законов.

Проверено:68pure checks,57UnityEditMode,7PlayMode; Windows build без ошибок/предупреждений. Native-клип реальной доставки и кадр естественно родившегося ребёнка находятся в репозитории.1000существ/30сек:131.87FPS,p99≈13.89мс на7950X/4090; это один профиль, не минимальные требования.

Караваны, монеты/плавка/полная кузница, исследования и автономные ресурсные войны ещё впереди. Бартер сейчас складской1:1, еда/доски частично общинные. Толпа возле фермы ещё пересекается. Это самостоятельная альфа, не завершённый WorldBox.
