## Что действительно нарисовано и что вычисляется

| Слой | Фактическое покрытие | Как считать |
|---|---|---|
| Исходные тела | 4 расы × взрослый мужчина / взрослая женщина / мальчик / девочка | 16 профилей |
| Ходьба | Каждый профиль: юг, запад, восток, север; 4 исходных рисунка на направление | 64 направленных последовательности, 256 исходных ячеек; **не 256 разных анимаций** |
| Покой | Удерживаемая поза исходной ходьбы | Отдельный нарисованный цикл idle пока отсутствует |
| Одежда взрослых | Житель, земледелец, лесоруб, охотник, животновод, торговец, плотник | 7 гражданских вариантов на каждом взрослом профиле |
| Детская одежда | Более простое оформление; взрослая профессия не выдаёт ребёнку взрослый наряд | Не 7 детских рабочих профессий |
| Рабочие предметы | Топор, кирка, мотыга, молоток; 4 направления × 4 вычисленные фазы | 64 ячейки предметов; не новые циклы тела и не инвентарь |
| Работа/нужды/общение | Смещения верхней части тела, масштаб/наклон/подскок и контекстные предметы из реального состояния | Производные жесты, перечислены ниже отдельно |

Исходная генерация дала листы 1254×1254 с нерегулярными промежутками. `OriginalCitizenAtlas` выделяет восемь строк и восемь фигур в строке по alpha, нормализует профиль к логическим 32×32 с общим контактом стоп, затем один раз компонует одежду. Рабочий atlas на момент кода — 1024×2112: 2048 сочетаний тела/профиля/слота одежды/направления/фазы плюс 64 предмета. Здесь есть повторяющиеся безопасные слоты для детей и недоступного Guard; размер atlas нельзя выдавать за количество уникальных анимаций или костюмов.

Пиксельная фильтрация — Point. Фазы ходьбы определяются `World.Tick`, `TaskStartedTick` и постоянным смещением по ID: четыре кадра по два тика, то есть 5 смен кадров/с при 10 тиках симуляции/с. Бегство меняет фазу каждый тик. На паузе фаза не должна идти от независимого времени рендера. Проверка этого требования принадлежит Unity/Player, а не подсчёту PNG.

## Связь с игровыми состояниями

`CitizenSprites` получает `UnitData`, реальное направление пути/цели, пол, возраст, профессию и состояние работы. Рендер ничего не добывает, не наносит урон и не создаёт вооружение. Все четыре цивилизованные расы проходят общий production-рендерер. Сортировка тел по Y/ID влияет только на отображение. Отрисовка ноши/животных/окружения остаётся отдельной частью `WorldView`.

| Состояние | Представление | Необходимое основание |
|---|---|---|
| Ходьба, возвращение, переноска, путь каравана/охотника, обход | Четыре фазы ходьбы с соответствующей семантической меткой | Непройденный путь; груз определяется `CarriedLoad` |
| Рубка / добыча | Производный рабочий жест + топор / кирка | Взрослый, ресурсный узел содержит материал, клетка не горит |
| Поле | Рабочий жест; ребёнок получает уменьшенный жест без тяжёлого предмета | Текущая задача `Farm`; право ребёнка работать решает симуляция |
| Обработка | Рабочий жест + молоток | Взрослый, `WorkTimer > 0` |
| Изготовление оборудования | Рабочий жест + молоток | Взрослый, `EquipmentProgress > 0`, нет переносимого груза |
| Стройка дороги/моста | Рабочий жест + молоток | Настоящий проект, этот работник, материалы доставлены, работник у места работы |
| Гражданский удар / удар охотника | Короткий выпад по сохранённому направлению | Взрослый, окно фактического `AttackTimer`; после окна новый удар не рисуется |
| Еда, питьё, общение, рыбалка | Небольшой производный жест верхней части тела | Соответствующая текущая задача |
| Отдых, учёба | Удерживаемая/изменённая поза | Соответствующая задача; не новый рисунок сна/чтения |
| Игра | Подскок | `Play`; в галерее показаны дети |
| Стадо / пивоварение | Небольшой рабочий жест при активном таймере | Текущая задача и `WorkTimer > 0` |

Мирный старт, запрет бесплатного Guard и правила детского труда остаются системами симуляции. Профессиональная одежда — внешний вид, не броня, оружие или экономическая стоимость. Статическая форма правителя/военная форма и отдельные нарисованные циклы смерти, плавания, верховой езды и всех производств этой итерацией не подтверждены.

## Нативная галерея и доказательства

Новый `NativeCitizenGallery` включается только явным `--citizen-gallery families|wardrobe|actions`. После инициализации он останавливает обычный игровой Bootstrap и скрывает его визуальные объекты только в этом специальном Player. Отдельный экземпляр production `CitizenSprites.Begin → Add → Submit` рисует подготовленных жителей. Пустой исходный `SimulationEngine.Step(0.1)` даёт реальные фиксированные тики отдельному состоянию отображения. Подготовленные жители не проходят AI, не образуют поселение и не сохраняются как игровое продолжение.

| Галерея | Количество фигур и назначение |
|---|---|
| families | 64: 16 семейных профилей в четырёх направлениях |
| wardrobe / male | 112: 4 расы × 7 гражданских профессий × 4 направления |
| wardrobe / female | Те же 112 сочетаний для женщин |
| actions / page 0, 1, 2 | По 32 фигуры: 8 карточек × 4 расы. Всего 24 карточки покрывают 23 значения `UnitTask`, включая две разные ресурсные задачи Gather |

Каждый кадр помечен **«изолированный Unity preview, подготовленные состояния, не игровой процесс»**. Ходьба идёт на месте. Ресурсы, груз, таймер выпада и полностью доставленный проект стройки заданы в fixture и отмечены в квитанции. Галерея не доказывает реальный бой, доставку, законность занятия или естественную прогрессию. Для этого нужна отдельная запись обычной игры.

[Run-CitizenGallery](../../Tools/CitizenGallery-README.md) подготавливает PNG, MP4 и квитанции: реальные интервалы кадров, тик, направления, индексы тела/предмета, семантическое действие и `DerivedGesture` каждого жителя, SHA256 исходников и бинарников. Соответствие бинарника исходникам устанавливает квитанция снимка сборки интегратора, не сам скрипт захвата. Исходные PNG сохраняются; MP4 кодирует записанные интервалы, не генерирует промежуточные фазы движения.

## Граница сравнения с WorldBox

Официальные описания подтверждают четыре расы, историческое введение детей/полов, культуру/одежду, ходьбу и некоторые рабочие действия. Публичная точная спецификация количества клипов, направлений и кадров не найдена; исторические добавления обликов не являются счётчиком анимаций. Непросмотренные видеоролики не выдаются за покадровый анализ. [Проверенные источники и неизвестные поля](../Research/WORLDBOX_ANIMATION_COVERAGE.md).

Поэтому здесь фиксируется **собственное измеримое покрытие**, а не равенство оригиналу по количеству и художественному качеству. Общее требование полноты WorldBox остаётся открытым.
