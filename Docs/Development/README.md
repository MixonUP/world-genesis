# Процесс разработки

World Genesis — собственная Unity-реализация симулятора мира с WorldBox как референсом. Полнота поведения остаётся целью; первый работающий срез не считается завершением игры.

Текущее состояние хранится в [STATE](../STATE.md), критерии — в [ACCEPTANCE](../ACCEPTANCE.md), карта соответствия — в [FEATURE_MAP](../FEATURE_MAP.md). Здесь собраны короткие записи хода разработки, агентные роли и отобранные кадры. Это материал для репозитория GitHub без личных переписок и необработанных данных окружения.

## Как читать доказательства

`prepared` означает, что файл или процедура подготовлены; `implemented-unverified` — код написан, но соответствующая проверка ещё не выполнена; `verified` — приложен результат конкретного испытания. Скриншот свидетельствует о внешнем виде, тест — о проверенном поведении. Художественное принятие пользователем фиксируется отдельно.

У каждого кадра сохраняются источник, ревизия, seed, размер карты и действия. Концепт, offline-рендер или автоматическая подготовка сцены всегда подписываются. Ранние записи об отсутствии кадров относятся к своему времени; новые Player-кадры перечислены в обновлении alpha выше.
