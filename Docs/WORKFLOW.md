# Методы работы и назначенные навыки

## Основной цикл

Один проверяемый результат за интеграционный шаг: выбрать сценарий → установить владельца данных → реализовать → проверить состояние → проверить настоящий вид/управление → исправить → сохранить доказательство и следующий шаг. Сначала один представитель семейства (тайл, юнит, дом, эффект), затем расширение.

Для сложной новой механики сначала маленький эксперимент с входами, ожидаемым результатом и критерием отказа. Не создавать отдельные демо-системы, которые не используются основной игрой. Ручной ввод и тестовые команды должны проходить одну производственную логику.

План и факт раздельны. Подготовленный скрипт, успешный импорт, пройденный тест, запуск Player и художественное принятие — разные состояния. Короткие записи текущего состояния в STATE, решения в DECISIONS, измерения в Evidence. Большой документ не заменяет запуска.

## Проверки по уровню

По уточнению пользователя о качестве выше Claude 5.5 действует [стандарт агента](Research/AGENT_QUALITY_STANDARD.md): 14 правил, исходные инструкции Anthropic/OpenAI и 8 сценариев будущего сравнения. Подготовлен [шаблон сложного шага](Templates/WORK_PACKET.md). Рекомендации внешних источников не включают подагентов или hooks автоматически; превосходство не заявлено и сравнительные прогоны не выполнены.

- Структура: пути, версии, ссылки, JSON и граф assembly references. Не доказывает импорт.
- EditMode: seed/команды, границы, навигация, ресурсы, сохранение, испорченные данные.
- PlayMode: сцена и подписки, ввод/UI, pause/resume, работа представлений, очистка.
- Player: реальное управление, save/load после перезапуска, нативные кадры/клипы, Profiler/измерения.
- Сравнение с WorldBox: конкретные свойства и открытые отличия, без процентов сходства из предположений.

Сцены/контент редактирует один интегратор. Независимые чтения допустимо выполнять пакетно. Параллельных агентов сейчас не назначать. Если позже поручены: отдельные пути, входы/выходы и интеграционный порядок до старта.
