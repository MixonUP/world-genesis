# Проверка игры

Следовать корневому AGENTS и `Docs/ACCEPTANCE.md`. Пока существуют только определения тестовых сборок; тестов нет.

EditMode: генерация по seed, край карты, путь после правки ландшафта, ресурсы/рост, последствия сил, владение/отношения, save-load-continue, отказ при повреждении данных.

PlayMode: обычный путь через сцену, ввод/UI и отсутствие click-through, камера, пауза, смена мира, удаление представлений/подписок/эффектов.

Проверять поведение, не дублировать реализацию. Сохранять seed/команды и NUnit XML. Ноль исполненных тестов — не PASS. Фиктивные тесты пустых классов для зелёного индикатора не нужны. Visual/performance acceptance — отдельно в настоящем Player; помощь тестового управления обозначать.
