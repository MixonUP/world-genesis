# World Genesis

Процедурная песочница бога на Unity: четыре народа, живые поселения, ресурсы, общество и погода. Самостоятельная реализация с WorldBox как референсом; полный объём коммерческой игры ещё не достигнут.

**0.8 — море и рынок.** [Windows-сборка](https://github.com/MixonUP/world-genesis/releases/tag/v0.8.0-alpha) · [пять кадров и ролик](Docs/Development/MARITIME_GALLERY.md) · [проверки и ограничения](Docs/Development/MARITIME_REPORT.md).

## В этой версии

- Порт, верфь, портовое управление. Соединённые портовые склады трёх уровней: **5000 → 10000 → 20000**, вместимость секций складывается; связь по суше или мостам.
- Три рыбацких типа, транспорт, торговое и боевое судно. Морские странники с конечным трюмом **5000 / 10000 / 20000**, покупка и продажа настоящих товаров за монеты, зарубежные рейсы, нападение и захват.
- Капитан и моряки — реальные жители. Они подходят к причалу, поднимаются на борт, едят и пьют в пути. **После высадки моряк возвращается к обычной работе.**
- Рынок учитывает существующие партии, деньги, сдачу и налог. Заказы показывают причины ожидания и направляют исследования, строительство и доставку. Исправлено застревание у двери.

## Запуск

Распакуйте Windows ZIP целиком и запустите WorldGenesis.exe, сохранив рядом папку данных и DLL. Локальная сборка: Builds/Windows-0.8.0/WorldGenesis.exe.

WASD / средняя кнопка — камера; колесо — масштаб; ЛКМ — инструмент; I — наблюдение; пробел — пауза; Home — весь мир; Ctrl+S / Ctrl+L — сохранение / загрузка; M — звук; F12 — снимок. В наблюдении выберите корабль для вкладок «Рейс», «Трюм», «Команда». [Подробное управление](Docs/Development/PLAY_GUIDE.md).

Разработка: WorldGenesis/, Unity **6000.0.45f1**, сцена Assets/_Project/Scenes/Main.unity. [Команды](Tools/README.md).
