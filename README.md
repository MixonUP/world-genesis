# World Genesis · Unity

Проект игры по референсу [WorldBox — God Simulator в Steam](https://store.steampowered.com/app/1206560/WorldBox__God_Simulator/).

**Текущий этап: реализация первого игрового среза.** Генератор мира, симуляция и Unity-интерфейс разрабатываются параллельно. Интеграция и игровые проверки ещё идут. World Genesis — рабочее название; полное соответствие WorldBox не достигнуто.

Unity-папка: `WorldGenesis/`, версия **6000.0.45f1**. Её можно добавить в Unity Hub через Add project from disk. Лицензия редактора подтверждена после запуска Unity Hub; первый импорт выполнен до стадии компиляции. Точные результаты интеграции — в [STATE](Docs/STATE.md).

Процесс разработки и роли агентов: [Development](Docs/Development/README.md). Репозиторий: [MixonUP/world-genesis](https://github.com/MixonUP/world-genesis), приватный.

Целевой проход: создать мир → заселить → наблюдать развитие → вмешаться → увидеть последствия → сохранить и продолжить.
