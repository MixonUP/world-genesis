# Демонстрационная сцена складов 0.5

Отдельная CLI-фикстура; игровой код не изменяет. Запуск из корня репозитория:

```powershell
dotnet run --project Tools/StorageShowcase/StorageShowcase.csproj --configuration Release
```

Необязательные аргументы: входной raw/envelope JSON, выходной envelope, путь квитанции. По умолчанию читается `Builds/transport-assisted-showcase-v050-bridge-complete.json`, при отсутствии — `Builds/transport-assisted-showcase-v050.json`. Вход сохраняется неизменным. Фикстура использует собственное явно подготовленное состояние мира, а не пользовательское сохранение.

Склад материалов и пищевой амбар создаются через `TryBuildInfrastructure`, затем каждый оплачивает три настоящих `TryUpgradeBuilding` до уровня 4. Выдаются ровно материалы этих действий: 88 досок, 8 кирпичей, 12 каменных блоков. Требуемые исследования и их зависимости выдаются явно; если выданное исследование было активным, его прежнее имя и прогресс записываются, активная запись очищается. Оставшаяся транспортная стройка, если она есть в запасном входе, отменяется штатной операцией с сохранением доставленных материалов на земле.

В новые здания добавляются **сгенерированные демонстрационные партии**: склад — камень 300 и волокно 100; амбар — зерно 300, сено 100 и ягоды 50. Это доказательство связи API, хранения и будущего отображения, **не доказательство естественного производства**, роста поселения или доставки этих товаров. Симуляционные тики здесь не выполняются. Входной мир также уже был assisted.

Проверяются полный `WorldState.Validate`, оба запрета пятого улучшения, точная оплата досок и сериализация/десериализация envelope схемы 1 с повторным Validate и сохранностью заполнения обоих зданий. Полная проверка загрузки через Unity `SaveStore` и художественный обзор требуют Player отдельно.
