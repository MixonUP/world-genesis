# Подготовленный производственный квартал

`dotnet restore Tools/ProductionShowcase/ProductionShowcase.csproj --configfile Tools/ProductionShowcase/NuGet.Config`

`dotnet run --project Tools/ProductionShowcase --no-restore -- Builds/production-showcase.save.json Evidence/Simulation/production-showcase.json`

Инструмент явно готовит ровный участок, исследования, строительный бюджет, сырьё и промежуточные товары для семи мастерских. Постройки оплачиваются через API; рабочие получают настоящие команды производства. Монетный двор должен принести ингредиенты с общего склада, остальные начинают с локально выданными входами. После записи сохранения проверяются120 обычных тиков продолжения. Сценарий проверяет интеграцию/отображение; естественное развитие измеряется отдельным ProductionProbe.

Камера `(59,62)`, zoom11. Для близкого просмотра кузницы — `(57,66)`, zoom7; плотника — `(57,56)`, zoom7. Player: `Builds/Windows-0.7.0/WorldGenesis.exe`. Фактические кадры и результат проверки публикуются только после успешной сборки.

Осадные изделия — разобранные комплекты плотника. Стрельба, экипаж и развёртывание в этом сценарии не подменяются декоративным эффектом.

После внедрения дверей обычный вариант сохраняется на30-м тике с фактическими работниками внутри. Третий аргумент --approach сохраняет нулевой тик и ставит кузнеца севернее здания: настоящая навигация обходит стену и приводит его к двери. Для кадров инспектора жителя используйте Run-Capture.ps1 -InspectOccupant вместе с координатами здания.
