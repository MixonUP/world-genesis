# MarketProbe · 0.8

Проверяет настоящую Simulation без Unity. Общие сценарии находятся в `WorldGenesis/Assets/_Project/Tests/EditMode/MarketTests.cs`: .NET использует System.Text.Json, Unity-обёртки — JsonUtility. Это авторские проверки реализации рынка; независимое ревью и нативная приёмка выполняются отдельно.

Из корня проекта:

```powershell
& 'C:/Program Files/dotnet/dotnet.exe' run --project Tools/MarketProbe --no-restore -- Evidence/Simulation/market-probe.json
& 'C:/Program Files/dotnet/dotnet.exe' run --project Tools/MarketProbe --no-restore -- --natural Evidence/Simulation/market-natural.json 1800
```

Последний необязательный аргумент после1800 выбирает один seed; по умолчанию1618033 и271828. Не использовать совпадающие имена evidence для разных снимков исходников. Перед первым запуском нужен `dotnet restore Tools/MarketProbe --configfile Tools/MarketProbe/NuGet.Config`; внешних пакетов нет. В ограниченном окружении глобальный NuGet.Config оказался недоступен: использована локальная папка `Builds/MarketProbeHome` как APPDATA только для процесса восстановления. Глобальная конфигурация не изменялась.

Обычный режим создаёт явно подготовленные контролируемые ситуации с конечным сырьём, деньгами и участниками. Проверки производства могут выдавать технологии/мастерские как начальные условия и не служат доказательством естественного старта.

Natural: карта128×128, обычные команды Spawn9 жителей каждой расы и3овцы около четырёх стартовых ориентиров; только Step(0.1), без грантов/подмен технологий, ресурсов, нужд, профессии или погоды. Ограничение180реальных секунд наseed. Пишет частичный результат, если лимит достигнут. Validate каждые100тиков и по краям, вместимость ноши каждыйтик. Итоговые сохранения — `Builds/MarketNatural/`; контрольные суммы, временные вехи технологий/изделий/мастерских, занятость, голод и причины ожидания — в receipt. Первые технологии фиксируются по миру, а не отдельно для каждого города; текущие состояния городов входят в300-секундные срезы. Счётчик sampledNeedStateSeconds — длительность видимой причины заказа, не доказанное время бездействия каждого жителя.

`AnalyzeBaseline.py` читает сохранённые миры0.7 и квитанцию `production-interior-natural-final-r2.json`, не применяя миграцию0.8. Он выдаёт `market-baseline-0.7-diagnosis.json`: проверяемые конечные препятствия цепочек и доступные временные срезы. Не приписывает непрерывные причины задержек данным, которых старый прогон не собирал.

Отчёт фиксирует SHA исходников до/после и сборки инструмента. `sourceUnchanged=false` не скрывается: такой прогон остаётся предварительным. .NET wall time не равен FPS Player; эти тесты не подтверждают художественное качество или достижимость всего дерева развития.

`CompareNatural.py` сверяет естественные миры0.7/0.8 и их SHA, сохраняет `market-natural-comparison.json`, выводит порты/флот, фактических владельцев одежды и расход завершённых рецептов. Это расчёт из сохранений и счётчиков, а не перезапуск мира или запись всех доставок.
