# Контролируемая демонстрация транспорта 0.5

```powershell
dotnet restore Tools/TransportShowcase/TransportShowcase.csproj --configfile Tools/SimulationProbe/NuGet.Config
dotnet run --project Tools/TransportShowcase/TransportShowcase.csproj --no-restore
```

Если изолированный subprocess не может читать пользовательский NuGet.Config, задайте для этого subprocess временный `APPDATA` внутри `Builds/`; глобальный профиль менять не требуется. Внешних пакетов нет.

Параметры: первый — префикс сохранений, второй — путь квитанции. Повторный запуск с теми же параметрами заменяет только эти генерируемые файлы. Для нового доказательства задавайте новый префикс/receipt.

Результаты по умолчанию:

- `Builds/transport-assisted-showcase-v050.json` — raw `WorldState`, пригодный для существующего native debug load.
- `Builds/transport-assisted-showcase-v050.save.json` — оболочка `Schema=1/Format=WorldGenesis/World`, пригодная для обычного SaveStore.
- `Builds/transport-assisted-showcase-v050-bridge-complete.json` и `.save.json` — более ранний момент, первый мост завершён.
- `Evidence/Simulation/transport-assisted-showcase-v050.json` — перечень помощи, реальные поставки, завершённые проекты, координаты камеры, SHA256 и проверки.

Это **контролируемый показ**, не естественное развитие. Мир 128² создаётся обычным генератором seed713; в нём оформляется участок 37×31. Выданы технологии с зависимостями, еда и ровно счета материалов каждого проекта, выбран взрослый строитель; отложены пересмотры указов/планирования, выключены старение/рождения/войны/естественный спавн фауны. Ни телепортации, ни ускорения рабочего таймера, ни бесплатной корзины/животного нет. Шаги — обычные `SimulationEngine.Step(.1f)`, нужды активны. Каждый тик проверяются save-инварианты и ноша≤1. Тропа уровня1 возникает из настоящих проходов. Уровни2–4 и мост строятся обычной производственной операцией с физической доставкой.

Сохранение фиксирует завершённый мост, все четыре уровня дорог, брод, овраг, холмы, возвышенность, болото, а также второй мост с доставленным материалом и следующей единицей на руках. Следующие100тиков исходного/сериализованного миров сравниваются полностью. Скриншот/Unity-проверку этот инструмент не выполняет.
