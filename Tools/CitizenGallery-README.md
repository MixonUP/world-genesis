# Нативная галерея жителей

Подготовлено 12.10.2026. Отдельный режим Player включается только аргументом `--citizen-gallery`. Обычный запуск игры не затрагивается. Код галереи подготовлен; запуск, компиляцию Unity и художественный просмотр выполняет интегратор. Этот документ сам по себе не подтверждает их прохождение.

Галерея использует настоящий `CitizenSprites.Begin → Add → Submit`, его atlas, материал, инструменты и quad batch. Изолированный пустой `SimulationEngine.Step(0.1)` даёт время 10 тиков/с; отдельное подготовленное состояние отображения получает его `Tick`. Сами жители не проходят AI, ходят на месте, состояния ресурсов/ноши/работы/выпада задаются явно. Это проверка отображения, не сохранение игровой сцены и не свидетельство естественной прогрессии. Дополнительный WorldView слой товаров/животных/окружения в галерею не входит. Полный игровой путь проверяется отдельным gameplay capture.

Сначала интегратор собирает текущий Player. Путь в командах нужно заменить на эту сборку: выпущенный старый 0.5.1 не содержит новую галерею.

```powershell
./Tools/Run-CitizenGallery.ps1 -Mode families -PlayerRelativePath Builds/Windows-0.6.0/WorldGenesis.exe
./Tools/Run-CitizenGallery.ps1 -Mode wardrobe -Sex male -PlayerRelativePath Builds/Windows-0.6.0/WorldGenesis.exe
./Tools/Run-CitizenGallery.ps1 -Mode wardrobe -Sex female -PlayerRelativePath Builds/Windows-0.6.0/WorldGenesis.exe
./Tools/Run-CitizenGallery.ps1 -Mode actions -ActionPage 0 -PlayerRelativePath Builds/Windows-0.6.0/WorldGenesis.exe
./Tools/Run-CitizenGallery.ps1 -Mode actions -ActionPage 1 -PlayerRelativePath Builds/Windows-0.6.0/WorldGenesis.exe
./Tools/Run-CitizenGallery.ps1 -Mode actions -ActionPage 2 -PlayerRelativePath Builds/Windows-0.6.0/WorldGenesis.exe
```

Скрипт не запускает Unity Editor и не собирает проект. Он запускает видимый уже собранный Player 1920×1080, ждёт до 90 секунд и кодирует собственные PNG в MP4 через существующий FFmpeg. При таймауте процесс не уничтожается автоматически. `-Seconds 1..20`, по умолчанию 6. Пример пути 0.6.0 — место назначения интегратора, не заявление о выпущенной версии.

| Режим | Содержание |
|---|---|
| families | 4 расы × мужчина/женщина/мальчик/девочка × юг/запад/восток/север = 64 фигуры, 16 семейных профилей |
| wardrobe | 4 расы × 7 гражданских профессий × 4 направления = 112 фигур выбранного пола; дети не получают взрослые костюмы |
| actions, 0 | Покой, ходьба, груз, рубка, добыча, поле, обработка, заданный таймер выпада |
| actions, 1 | Бегство, еда, отдых, общение, детская игра, детская учёба, питьё, рыбалка |
| actions, 2 | Стадо, пивоварение, ремесло, стройка, переноска, караван, путь охотника, обход |

Действия — 8 столбцов × 4 расы = 32 фигуры на странице. Дети используются только в карточках игры/учёбы. `Guard` не используется; одежды не создают вооружение. Удар — подготовленный `AttackTimer`, поэтому подпись не утверждает, что состоялся реальный бой. Производные жесты не считаются дополнительными нарисованными клипами; это записано в `derivedGestures` каждого кадра.

Выход: исходные PNG и `gallery.json` в `Builds/CaptureFrames/`; MP4, первый PNG, JSON с позами/тиками и `.build.json` с SHA256 бинарников/исходников/PNG в `Evidence/Captures/`. На изображении постоянно видны статус preview и тик. Квитанция честно не устанавливает соответствие исходников бинарникам: для этого нужна квитанция снимка сборки интегратора. Интервалы реального времени из PNG сохраняются при кодировании; 30 fps MP4 повторяет 10 Hz образцы, промежуточные фазы не генерируются.

Просмотр должен проверить четыре направления, ноги/опору, отсутствие отсечения в крайних кадрах, масштаб рас/детей, согласованность одежды в движении и читаемость при обычном игровом масштабе. Успешная техническая запись и хеши не означают художественного принятия пользователем.
