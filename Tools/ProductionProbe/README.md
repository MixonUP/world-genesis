# Независимые проверки производства 0.7

Инструмент компилирует настоящие `Simulation/**/*.cs` и общий файл [ProductionTests.cs](../../WorldGenesis/Assets/_Project/Tests/EditMode/ProductionTests.cs). Отдельной упрощённой модели производства нет. В Unity те же25 сценариев обёрнуты NUnit и используют `JsonUtility`; автономный .NET-вариант сериализует через `System.Text.Json`. Совпадение результата двух сериализаторов должен подтвердить отдельный Unity-run интегратора.

## Запуск из корня проекта

```powershell
$env:APPDATA = Join-Path (Get-Location) 'Builds/ProductionDotnetProfile'
& 'C:/Program Files/dotnet/dotnet.exe' restore Tools/ProductionProbe/ProductionProbe.csproj --configfile Tools/ProductionProbe/NuGet.Config
& 'C:/Program Files/dotnet/dotnet.exe' run --no-restore --project Tools/ProductionProbe/ProductionProbe.csproj -- Evidence/Simulation/production-probe-final.json
& 'C:/Program Files/dotnet/dotnet.exe' run --no-build --no-restore --project Tools/ProductionProbe/ProductionProbe.csproj -- --natural Evidence/Simulation/production-natural-final.json 1800
```

`APPDATA` выше задаётся только в процессе диагностической оболочки: локальный профиль нужен, чтобы restore не зависел от пользовательского NuGet.Config. Источники пакетов пусты, сторонние пакеты не устанавливаются. Для повторных результатов применять новые имена квитанций. Последний аргумент после длительности позволяет диагностировать один seed, например `1800 1618033`; штатный прогон без него проверяет1618033 и271828. Бюджет natural — до180 реальных секунд на seed. Код2 означает, что инварианты прошли, но заданная длительность не достигнута; это не полный PASS сценария.

## Покрытие

- Все27 рецептов: точный локальный расход каждой позиции, конечный товар на физическом складе, профессия, счётчик выпуска; монеты10шт только после расхода слитка и угля.
- Связанные цепочки без выдачи промежуточных промышленных товаров: предыдущий продукт берётся настоящим работником из предыдущего цеха, недостающие промежуточные партии действительно производятся повторно.
- Две ноги доставки материала, отдельная ноша шкур/волокна; отказ при разрыве пути, сохранность уже поднятого груза после разрыва.
- Один работник на цех, два цеха с последней общей партией; полная локальная партия не блокируется чужой неудовлетворённой заявкой; безопасная смена брошенного недостижимого рецепта.
- Полный выходной склад, недостаточный вход, неподходящее здание, исследования, возраст, чужой город, приватные/налоговые товары.
- Отмена после подъёма груза, смерть, разрушение и повторная очистка; миграция ResourceVersion3 массивов18→45, включая оплаченные строительные материалы, без расхода RNG/ID.
- Save/load посреди перевозки и обработки с одинаковым продолжением; ошибочные/нечисловые данные и поддельные legacy-поля отвергаются.
- Физическая выдача инструментов/одежды, повторная выдача запрещена, предметы выпадают после смерти. На одинаковом реальном `UpdateUnit` инструменты ускоряют выпуск, одежда снижает усталость. Доставленная мебель повышает комфорт дома.
- Осадные комплекты/боезапас изготавливает плотник в столярной мастерской после исследования. Выпуск не создаёт `Guard` и не доказывает действующую осадную боёвку.
- Два сборщика одной конечной кучки: второй не получает нулевой груз с ненулевым типом.

Controlled-помощь: плоская карта, взрослые, заданные технологии и здания, точные входные материалы; отключены старение/рождения/случайная погода. В отдельных проверках начальная позиция поставлена у цеха. В связанной цепи выданы сырьё, базовые доски и корзина3, потребности сбрасываются **между** партиями; движение и списание внутри партии настоящие. Это проверяет производство и транспорт, не добычу всех ресурсов и не естественное открытие всех технологий.

Естественный режим отдельно: генерация128×128, обычный `Spawn` по9 представителей каждого народа и по3 овцы возле стандартных четырёх ориентиров. После старта только `Step(.1)` — без выдачи сырья, исследований, оснащения, должностей, изменения погоды/законов/потребностей. Каждые100 тиков и по краям — `World.Validate`; каждый тик — фактическая ноша каждого существа. Записываются первые цеха/товары/технологии, выпуск, выдачи, установка мебели, запасы, причины ожидания и промежуточные состояния через300simsec. При ошибке полный диагностический мир сохраняется в игнорируемом `Builds/ProductionProbeFailures`, путь есть в квитанции.
