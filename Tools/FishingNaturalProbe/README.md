# Естественная рыбалка: .NET smoke

13.10.2026, 14:59 +03:00. Проверяется production `Simulation` без Unity. Это не native performance, не визуальная приёмка и не доказательство полного естественного развития снасти 1→5.

```powershell
$env:APPDATA = Join-Path (Get-Location).Path 'Builds/FishingNaturalDotnetProfile'
dotnet restore Tools/FishingNaturalProbe/FishingNaturalProbe.csproj --configfile Tools/FishingNaturalProbe/NuGet.Config --ignore-failed-sources
dotnet run --project Tools/FishingNaturalProbe/FishingNaturalProbe.csproj --configuration Release --no-restore -- Evidence/Simulation/fishing-natural.json 600 110
```

Рабочая директория — корень проекта. Первое число — запрошенные секунды симуляции на каждый seed (1…600), второе — общий лимит реального времени прогона (до 110 с); каждому seed выделяется половина. Если длительность не достигнута, квитанция содержит фактические тики и `truncatedByWallBudget=true`, код выхода 2. Ошибка инварианта или изменение исходников даёт 1. Полный проход даёт 0. Внешних NuGet-пакетов нет. Временный APPDATA действует только в запущенном shell и не меняет глобальный профиль пользователя. Повторный эксперимент сохранять под новым именем receipt.

Старт — `WorldGenerator.Generate(seed,128,128)` и те же обычные команды, что у игрового `GameBootstrap.SeedLife`: поиск ближайшей пригодной позиции к четырём опорным точкам, `Spawn` по 9 жителей соответствующей расы и по 3 овцы. Создание/объединение поселений и начальные ресурсы определяет настоящий контракт `Spawn`. После этого вызывается только `Step(.1)`. Исследования, снасти, товары, должности, погода, потребности и законы вручную не назначаются. Нет команд принудительной рыбалки или изменения водоёмов.

`World.Validate` выполняется в начале, каждые 100 тиков и в конце. Каждый тик проверяется конечность ноши/вместимости и `CarriedLoad <= CarryCapacityFor`. Счётчик улова читается по жителям, включая сохранённые ссылки на умерших; `FishSpeciesId` используется только при изменении `FishCaughtCount`. Записываются активные рыболовы, максимальные грейды, виды улова, промежуточные запасы каждые 60 секунд, максимальное количество рыбных товаров на складах и итоговые товары на руках/земле/в sink.

## Исполненный прогон

[Квитанция fishing-natural.json](../../Evidence/Simulation/fishing-natural.json). Автор Simulation подтвердил freeze перед запуском. SHA256 всех Simulation-файлов не изменились за время эксперимента; квитанция содержит их значения и хеш исполняемой сборки probe. Оба seed достигли 600 секунд / 6000 тиков, суммарное реальное время 13.26 с; временной предел не сработал. Это скорость автономного .NET-инструмента, её нельзя сравнивать с FPS Unity Player.

Суммарно 124 проверки мира и 889 565 проверок ноши прошли. В конце первого мира 3 единицы рыбы ещё на руках, во втором — 0; складской Fish в обоих равен 0. Это не отсутствие доставки: каждый мир действительно имел до 3 единиц на складах, затем код перерабатывает обычную рыбу в еду. Эти агрегаты не объявляются отдельным точным счётчиком съеденных рыб.

Улучшений снасти не наблюдалось. К финалу ни одно поселение не открыло `f06_river_fishing`, необходимую для грейда 2; поэтому данный короткий естественный прогон не подтверждает даже естественное 1→2, тем более 1→5. Контролируемые тесты рецептов с заранее заданными технологиями и материалами являются другим видом доказательств. Редкости не появлялись у начинающих, как и требуется контрактом.

## Независимое read-only ревью

После прогона прочитаны `World/FishingData.cs`, `Entities/FishingSimulation.cs`, рыболовные изменения `AgriculturalWork.cs`, `AgricultureEquipment.cs`, `WorkshopSupply.cs`, `World/AgricultureData.cs`, `World/StorageCapacity.cs` и участки `SimulationEngine.cs` о выборе/выполнении занятий. Код Simulation/Runtime, тесты владельца, Unity и Git не менялись и не запускались этим ревьюером.

| Проверенный путь | Вывод по коду и выполненному smoke |
|---|---|
| Запуск/завершение заброса | Взрослый, запас не менее одной рыбы, вместимость, достижимый берег и принимающее хранилище; проверка активности повторяется до таймера и RNG. После завершения списывается одна единица биомассы, рыба появляется у жителя |
| Редкий побочный материал | Создаётся отдельная наземная партия через `DropAgriculturalLoot`; не удалённое начисление складу, не монеты. В естественном smoke редкие ветви не исполнились |
| Крафт удочки | Рецепт требует последовательный предыдущий грейд и исследования; `SupplyAgriculturalWorkshop` переносит входы к лесопилке, локальное списание происходит при завершении. Естественные крафты в этом прогоне не достигнуты |
| Старое сохранение | `MigrateAgriculture` расширяет массивы 13→17 через `Array.Resize`, `MigrateFishing` выдаёт взрослым только примитивный грейд. Само ревью не подменяет отдельные тесты save/load владельца |
| Типы запасов | Fish/DelicacyFish принимаются как еда; RiverPearl/AncientScale — материалы. В список конвертации в Food входят только съедобные рыбные продукты |
| Детский доступ | `RodLevel` для ребёнка/животного равен 0, публичный запуск рыбалки и рецепт оборудования отвергают их; снасти не становятся военным снаряжением |

Конкретных новых P0/P1 в этих прочитанных путях и двух естественных прогонах не обнаружено. Это ограниченное ревью, не гарантия отсутствия всех дефектов. Видимая граница баланса — естественное исследование и изготовление следующей снасти ещё не показано за 600 секунд; объявлять полный путь 1→5 естественно работающим по этому результату нельзя.
