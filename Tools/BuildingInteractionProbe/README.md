# Входы, стены и внутренние занятия зданий

Отдельные общие сценарии `BuildingInteractionTests.cs` исполняют настоящий `SimulationEngine.Step(.1)`. В Unity обёртки используют `JsonUtility`, в .NET — `System.Text.Json` с полями. Это дополнение к неизменённому набору из25 производственных сценариев, не его замена.

Из корня проекта:

```powershell
$env:APPDATA = Join-Path (Get-Location) 'Builds/BuildingInteractionDotnetProfile'
& 'C:/Program Files/dotnet/dotnet.exe' restore Tools/BuildingInteractionProbe/BuildingInteractionProbe.csproj --configfile Tools/BuildingInteractionProbe/NuGet.Config
& 'C:/Program Files/dotnet/dotnet.exe' run --no-restore --project Tools/BuildingInteractionProbe/BuildingInteractionProbe.csproj -- Evidence/Simulation/building-interaction-probe.json
```

Второй аргумент после пути квитанции — необязательная подстрока имени сценария. Нулевой набор, сбой проверки или изменение SHA Simulation во время прогона дают ненулевой код завершения. Квитанция содержит имена проверок, ошибки, SHA исходников/сборки и описание помощи.

Покрытие: непроходимый footprint и обход, подход к сохранённой двери, выход перед новым маршрутом, производство/смешанные входы/выдача внутри, отдых в доме, вместимость/право входа, эвакуация при огне/сносе, смерть и груз, затопленная дверь, полностью запертый горящий дом, save во время подхода и внутри, legacy координаты на стенах, испорченные ссылки/таймер/дверь/версия. Полная валидация и предел ноши проверяются каждый исполняемый тик.

Помощь controlled-сценариев: плоская карта40×40, заданные взрослые/здания/исследования/сырьё/потребности; старение, рождение и случайная погода выключены. Начальные позиции некоторых жителей поставлены у входа. «Затопленная дверь» задаётся настоящей командой покраски глубокой воды, не выдаётся за естественный погодный паводок. Пожар задаётся реальным полем Fire; эвакуация и урон исполняются Simulation. Вместимость тестируется явными посетителями. Эти сценарии не доказывают естественное развитие, визуальную сортировку/скрытие спрайтов, native FPS, художественное принятие или30минут Player.
